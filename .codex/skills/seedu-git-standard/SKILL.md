# SE-EDU Git Standard

Use this skill before proposing, reviewing, or creating any commit in this
repository. Also use it when naming a new branch.

Follow [the project reference](references/git-conventions.md), a focused local
transcription of the [SE-EDU Git conventions]
(https://se-education.org/guides/conventions/git.html). Consult the official
guide if a detail is unclear.

Before committing, verify that:

- the subject is imperative, capitalized, has no final period, and is ideally
  50 characters or fewer (never more than 72);
- a non-trivial change has a blank-line-separated body wrapped at 72
  characters that explains what changed and why, rather than implementation
  mechanics; and
- the commit is cohesive. Split an overly broad change into smaller commits
  when that makes the history clearer.

Do not create a commit unless the user has authorized one. This skill governs
how an authorized commit is prepared; it does not grant commit permission.
